# CS-370
Current/Emerging Trends in CS

Overview

This project uses deep Q-learning to train an intelligent agent (pirate) to find the treasure in a maze. The agent learns the best path by trying different moves and improving over time.

What I Did

I was given starter code for the maze and supporting classes. My main task was to complete the qtrain() function.

I:

Built the training loop
Used exploration and exploitation to choose actions
Stored past experiences
Trained the model using batch data
Updated the target network
Tracked win rate to measure progress
What I Learned

I learned how reinforcement learning works and how an agent improves using rewards and penalties. I also learned how neural networks are used to predict the best action based on the current state.

Computer Science Connection

Computer scientists create systems that solve problems using data and algorithms. This project shows how machine learning can be used for decision-making, like in real-world systems such as robotics or self-driving cars.

My Approach

I broke the problem into steps:

Reviewed the starter code
Followed the pseudocode
Tested with small values first
Adjusted based on results
Ethical Responsibility

Machine learning systems can be biased if the data is not balanced. It is important to build systems that are fair, accurate, and safe for users.

Conclusion

This project shows how reinforcement learning and neural networks can work together to solve problems and improve over time.
